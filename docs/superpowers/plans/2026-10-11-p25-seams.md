## 7. Task 3：Core 前进式字节读取器（A1）

公开 API（固定），命名空间 `Junevy.Communication.Core.Buffers`：
```csharp
/// 成员名与 System.Buffers.SequenceReader<T> 一致（net472 没有该类型，P25-D6）。
public ref struct ByteSequenceReader
{
    public ByteSequenceReader(ReadOnlySequence<byte> sequence);
    public ReadOnlySequence<byte> Sequence { get; }
    public SequencePosition Position { get; }
    public long Consumed { get; }
    public long Remaining { get; }
    public bool End { get; }
    public bool TryRead(out byte value);
    public bool TryPeek(out byte value);
    public void Advance(long count);   // count < 0 或超过 Remaining 抛 ArgumentOutOfRangeException
}
```
- 实现跨段读取时只在段边界取下一段，不复制数据。
