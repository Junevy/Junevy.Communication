## 解决方案布局

解决方案文件为 XML 格式 `.slnx`，含三个项目：

```text
Junevy.Communication/
├── Junevy.Communication.slnx              # 解决方案（XML 格式）
├── Junevy.Communication.Modbus/           # ★ 类库本体（net472;net8.0）
│   └── README.md                          # NuGet 包内 README（68 行，英文）
├── Junevy.Communication.Modbus.Tests/     # xUnit 单元/集成测试（net8.0）
├── Junevy.Communication.Test/             # WPF 手动联机测试工具（net8.0-windows）
├── Skills/using-junevy-modbus/SKILL.md    # 仓库内智能体 Skill
├── docs/superpowers/plans/                # 实施计划文档（2026-10-05 审查修复）

├── CHANGELOG.md                           # 变更日志（中文）
└── AGENTS.md                              # 仓库开发约定
```

## 类库目标框架与依赖

多目标 `net472;net8.0`，`LangVersion=latest`，可空引用启用，生成 XML 文档文件（`CS1591` 抑制——公共成员 XML 注释未全覆盖，文档全覆盖是后续专项）。

NuGet 元数据：`PackageId=Junevy.Communication.Modbus`，`Version=2.0.0`，`MIT` 许可证表达式，`GeneratePackageOnBuild=true`（每次构建产出 nupkg），仓库地址 `https://github.com/Junevy/Junevy.Communication`。

**库依赖（全部与 net472 兼容）**：

| 包 | 版本 | 用途 |
|---|---|---|
| Microsoft.Extensions.DependencyInjection.Abstractions | 8.0.0 | DI 注册扩展 |
| Microsoft.Extensions.Logging.Abstractions | 8.0.0 | 日志抽象（客户端/工厂全部面向 `ILogger<T>`） |
| Microsoft.Bcl.AsyncInterfaces | 8.0.0 | net472 上的 `IAsyncDisposable`/`ValueTask` |
| System.IO.Ports | 8.0.0 | RTU 串口 |
| System.Buffers / System.Memory / System.Threading.Tasks.Extensions | 4.5.1 / 4.5.5 / 4.5.4 | `ArrayPool` / `Span` / net472 异步支持 |

**约束**：库项目不新增外部包依赖（2026-10-05 重构计划的全局约束，见 [[变更与决策/设计决策记录]]）。

## 测试项目依赖

xUnit 2.5.3 + xunit.runner.visualstudio 2.5.3 + Moq 4.20.72 + Microsoft.NET.Test.Sdk 17.8.0 + coverlet.collector 6.0.0 + Microsoft.Extensions.DependencyInjection 8.0.0。目标 net8.0 单框架（测试不受 net472 多目标约束，但库代码本身必须兼容 net472）。

## WPF 手动测试工具（Junevy.Communication.Test）

- net8.0-windows，`UseWPF`，**非自动化测试**——人肉联机验证 TCP/RTU 真实设备用的 UI。
- 技术栈：CommunityToolkit.Mvvm 8.4.1（`ObservableObject`/`RelayCommand`）、Serilog（`4.3.2-dev-02419` + Extensions.Logging + Sinks.File 文件日志）、Microsoft.Extensions.DependencyInjection 8.0.0。
- 组成：`MainWindow.xaml.cs` + `MainWindowViewModel`（MVVM）、`MbCmd`（功能码选择枚举）、`ModbusData`（数据行模型）、四个转换器（`BoolToColorConverter`、`EnumToBoolConverter`、`LengthEnableConverter`、`ReverseBoolConverter`）。
- 历史注记：`ModbusRequest` 曾内嵌 UI 事件（供此工具用），2026-10-05 重构已移除，`ModbusRequest` 收敛为纯数据类；UI 联动改由 ViewModel 层驱动。
