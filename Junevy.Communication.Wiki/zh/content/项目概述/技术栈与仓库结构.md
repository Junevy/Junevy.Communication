## 解决方案布局

```text

├── Junevy.Communication.slnx                  # 解决方案（XML 格式，14 个项目）

│   ├── Junevy.Communication.Common.props      # 通道族库项目的公共设置（D2）
│   ├── Junevy.Communication.Tests.props       # 通道族测试项目的公共设置
```

## Modbus 类库目标框架与依赖

多目标 `net472;net8.0`，`LangVersion=latest`，可空引用启用，生成 XML 文档文件（`CS1591` 抑制——公共成员 XML 注释未全覆盖，文档全覆盖是后续专项）。

NuGet 元数据：`PackageId=Junevy.Communication.Modbus`，`Version=2.0.0`，`MIT` 许可证表达式，`GeneratePackageOnBuild=true`（每次构建产出 nupkg），仓库地址 `https://github.com/Junevy/Junevy.Communication`。

**库依赖（全部与 net472 兼容）**：

| 包 | 版本 | 用途 |
|---|---|---|
| Microsoft.Extensions.DependencyInjection.Abstractions | 8.0.0 | DI 注册扩展 |
| Microsoft.Extensions.Logging.Abstractions | 8.0.0 | 日志抽象（客户端/工厂全部面向 `ILogger<T>`） |
| Microsoft.Bcl.AsyncInterfaces | 8.0.0 | net472 上的 `IAsyncDisposable`/`ValueTask` |
| System.IO.Ports | 8.0.0 | RTU 串口 |
| System.Buffers / System.Memory / System.Threading.Tasks.Extensions | 4.5.1 / 4.5.5 / 4.5.4 | `ArrayPool` / `Span` / net472 异步支持 |

**约束（Modbus）**：库项目不新增外部包依赖（2026-10-05 重构计划的全局约束，见 [[变更与决策/设计决策记录]]）。通道族不受此约束，见下节。

## 通讯通道族类库（Core / Channels / Tcp / Udp / Serial）

- 版本 `1.0.0-preview.1`，由 `build/Junevy.Communication.Common.props` 统一设置（D1，未发布）。
- 目标框架 `net472;net8.0`；`Nullable`、`LangVersion=latest`、`GenerateDocumentationFile`、`TreatWarningsAsErrors=true`，**不抑制 CS1591**（D3）。
- 每个库项目的 csproj 显式 `Import` `build/Junevy.Communication.Common.props`（D2：不使用 `Directory.Build.props`，避免影响 Modbus）。`Testing` 项目之外的库项目 `GeneratePackageOnBuild=true`，并通过 `PackageReadmeFile` 打包本包的英文 README.md。
- 包依赖（csproj 与打包后的 nuspec 一致）：

| 项目 | 依赖 | 说明 |
|---|---|---|
| `Junevy.Communication.Core` | `Microsoft.Bcl.AsyncInterfaces` 8.0.0、`Microsoft.Extensions.DependencyInjection.Abstractions` 8.0.0、`Microsoft.Extensions.Logging.Abstractions` 8.0.0、`System.Memory` 4.5.5 | 不依赖 Pipelines 与 Channels（R1） |
| `Junevy.Communication.Channels` | 项目引用 Core；`System.IO.Pipelines` 8.0.0、`System.Threading.Channels` 8.0.0 | `InternalsVisibleTo` 开放给 `Tcp`、`Udp` |
| `Junevy.Communication.Tcp` | 项目引用 Channels | TLS 使用 BCL 的 `SslStream`，没有额外包 |
| `Junevy.Communication.Udp` | 项目引用 Channels | 没有额外包 |
| `Junevy.Communication.Serial` | 项目引用 Channels；`System.IO.Ports` 8.0.0 | 只使用公开基类，不开放 `internal` |
| `Junevy.Communication.Testing` | 项目引用 Channels | `IsPackable=false`，`GeneratePackageOnBuild=false`，不发布 |

依赖规则与理由见 [[架构设计/通讯库总体架构（协议族）]]。

## 测试项目依赖

Modbus 测试项目：xUnit 2.5.3 + xunit.runner.visualstudio 2.5.3 + Moq 4.20.72 + Microsoft.NET.Test.Sdk 17.8.0 + coverlet.collector 6.0.0 + Microsoft.Extensions.DependencyInjection 8.0.0。目标 net8.0 单框架（测试不受 net472 多目标约束，但库代码本身必须兼容 net472）。

通道族测试项目（`build/Junevy.Communication.Tests.props`）：Microsoft.NET.Test.Sdk 17.8.0、xunit 2.5.3、xunit.runner.visualstudio 2.5.3、coverlet.collector 6.0.0、Microsoft.Extensions.DependencyInjection 8.0.0；**不使用 Moq**。目标 `net8.0;net472`，`TestTfmsInParallel=false`。测试套件 `Junevy.Communication.Testing` 为项目引用，组件与用法见 [[测试/测试工程与验收方式]]。

## WPF 手动测试工具（Junevy.Communication.Test）

- net8.0-windows，`UseWPF`，**非自动化测试**——人肉联机验证 TCP/RTU 真实设备用的 UI。
- 技术栈：CommunityToolkit.Mvvm 8.4.1（`ObservableObject`/`RelayCommand`）、Serilog（`4.3.2-dev-02419` + Extensions.Logging + Sinks.File 文件日志）、Microsoft.Extensions.DependencyInjection 8.0.0。
- 组成：`MainWindow.xaml.cs` + `MainWindowViewModel`（MVVM）、`MbCmd`（功能码选择枚举）、`ModbusData`（数据行模型）、四个转换器（`BoolToColorConverter`、`EnumToBoolConverter`、`LengthEnableConverter`、`ReverseBoolConverter`）。
- 历史注记：`ModbusRequest` 曾内嵌 UI 事件（供此工具用），2026-10-05 重构已移除，`ModbusRequest` 收敛为纯数据类；UI 联动改由 ViewModel 层驱动。

## 构建与测试命令

```bash
dotnet build Junevy.Communication.slnx -c Debug      # 或指定 csproj
dotnet build Junevy.Communication.slnx -c Release
dotnet test Junevy.Communication.slnx -c Debug       # 全解决方案，两个目标
dotnet test Junevy.Communication.Modbus.Tests        # Modbus 基线 405/405（约 39 秒）
```

2026-10-10 全解决方案基线（分支 `feat/channels-p1`，commit `114d588`，Debug）：Modbus 405（net8.0）；通道族 Core 43、Channels 235、Tcp 116、Udp 32、Serial 57 + 2 跳过，每个测试项目在 net8.0 与 net472 上各一次。新库项目编译无警告，Modbus 项目仍有既有告警。

测试细节与当前已知构建告警清单见 [[测试/测试工程与验收方式]]。
