## 路径一：手动 `new`（单连接、简单场景）

### Modbus TCP

```csharp
using Junevy.Communication.Modbus.Extensions;
using Junevy.Communication.Modbus.Tcp;

using var modbus = new ModbusTcpClient(new ModbusTcpClientConfig
{
    Address = "192.168.1.100",
    Port = 502,               // 默认 502；普通可写属性，没有 SetPort() 方法
    ConnectTimeout = 2000,
    ReadTimeout = 2000,
    WriteTimeout = 2000
});

if (!modbus.Connect())        // 返回 bool，不抛异常
    return;

var result = modbus.ReadHoldingRegisters(slaveId: 1, start: 0, length: 4);
Console.WriteLine(result.IsSuccess
    ? string.Join(", ", result.Data!)      // ushort[]
    : $"{result.ErrorMessage} [{result.ErrorKind}]");

modbus.Disconnect();
```

### Modbus RTU

```csharp
using System.IO.Ports;
using Junevy.Communication.Modbus.Extensions;
using Junevy.Communication.Modbus.Rtu;

using var modbus = new ModbusRtuClient(new ModbusRtuClientConfig
{
    PortName = "COM3",
    BaudRate = 9600,
    Parity = Parity.None,
    DataBits = 8,
    StopBits = StopBits.One,
    ReadTimeout = 2000,
    WriteTimeout = 2000
});

modbus.Connect();
var write = modbus.WriteSingleRegister(slaveId: 1, start: 100, value: 1234);
modbus.Disconnect();
```

## 路径二：工厂 + Microsoft DI（多连接、服务端推荐）

```csharp
using Junevy.Communication.Modbus.DependencyInjection;
using Junevy.Communication.Modbus.Factory;
using Microsoft.Extensions.DependencyInjection;

var services = new ServiceCollection();
services.AddLogging();
services.AddModbusFactory();                       // 一行注册全部依赖

using var provider = services.BuildServiceProvider();
var factory = provider.GetRequiredService<IModbusFactory>();

var plc = factory.GetOrAdd("plc-1", new ModbusTcpClientConfig
{
    Address = "192.168.1.100",
    Reconnect = true,                              // 长运行服务建议开启
    RetryCount = 3,
    RetryInterval = 200
});
plc.Connect();

var coils = await plc.ReadCoilsAsync(slaveId: 1, start: 0, length: 8);
```

**RS-485 多从站**：一条物理串口注册一个连接，逻辑从站用别名指向它：

```csharp
factory.GetOrAdd("rs485-bus", new ModbusRtuClientConfig { PortName = "COM3" });
factory.RegisterAlias("slave-1", "rs485-bus");
factory.RegisterAlias("slave-2", "rs485-bus");
```

别名机制、生命周期与并发语义见 [[API参考/工厂与依赖注入]]。

## 路径三：无 Microsoft DI（Prism / DryIoc / Unity 等）

```csharp
using Junevy.Communication.Modbus.Factory;

// 例如在 Prism 的 RegisterTypes(IContainerRegistry containerRegistry) 中：
var loggerFactory = LoggerFactory.Create(b => b.AddSerilog(Log.Logger)); // 或 NullLoggerFactory.Instance
var factory = ModbusFactoryBuilder.Create()
    .WithLoggerFactory(loggerFactory)      // 可选：工厂与其创建的每个客户端共用
    .WithConnectionManager(manager)        // 可选：与宿主容器共享注册表
    .Build();

containerRegistry.RegisterInstance<IModbusFactory>(factory);
```

- 未设置的选项与 `AddModbusFactory` 的 DI 默认值一致；不需要引用任何 Microsoft DI 包（仍需 Logging.Abstractions）。
- `Build()` 每次调用返回**独立**工厂；应用关闭时 Dispose 工厂（它拥有全部连接）。
- 该构建器由 commit `bb3c6f9` 引入，随后 `74a3ed4` 打通 Microsoft DI 与 Prism DryIoc 的共享注册表。

## 原始请求 API（自定义行为设备）

```csharp
using Junevy.Communication.Modbus.Core.Models;

var raw = plc.Request(new ModbusRequest
{
    SlaveId = 1,
    FunctionCode = ModbusFunctionCode.Diagnostics,
    Data = new byte[] { 0x00, 0x00, 0x12, 0x34 }   // Data 布局随功能码变化，见数据模型笔记
});
```

`ModbusRequest` 是纯数据类，库不修改它的协议语义字段（TCP 客户端仅回写 `TransactionId` 用于响应匹配）。

## 新会话三个必记约定

1. **分支先看 `IsSuccess`**，`ErrorKind` 用于机器决策；`ModbusException` 类失败已被库判为终态、**绝不重试**，调用方也不要自己重试。
2. **地址是协议级零基地址**（协议线上地址，非 "40001" 式 Plc 地址别名）。
3. **每连接一次一个请求**（内部 `SemaphoreSlim` 串行化）；高吞吐请用多个连接（工厂多 key），不要并发轰同一个客户端。
