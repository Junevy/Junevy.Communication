## 路径一：手动创建（单连接、简单场景）

### Modbus TCP（MBAP）

```csharp
using Junevy.Communication.Modbus;
using Junevy.Communication.Plc;
using Junevy.Communication.Tcp;
using Junevy.Communication.Core.Results;

using ModbusClient client = ModbusClient.Create(
    new TcpClientChannelConfig { Host = "192.168.1.10", Port = 502 },
    new ModbusClientOptions { UnitId = 1 });

CommResult connected = await client.ConnectAsync();
CommResult<ushort[]> registers = await client.ReadUInt16Async("HR100", 2);
CommResult written = await client.WriteUInt16Async("HR100", 1234);
```

创建不会连接，需要显式 `ConnectAsync()`。

### RTU over 串口

串口上的默认分帧是 RTU，不需要设置分帧选项。

```csharp
using Junevy.Communication.Modbus;
using Junevy.Communication.Plc;
using Junevy.Communication.Serial;
using Junevy.Communication.Core.Results;

using ModbusClient client = ModbusClient.Create(
    new SerialChannelConfig { PortName = "COM3", BaudRate = 9600 },
    new ModbusClientOptions { UnitId = 1 });

await client.ConnectAsync();
CommResult<bool[]> coils = await client.ReadBitsAsync("C0", 8);
```

### RTU over TCP（网关或串口服务器）

```csharp
using Junevy.Communication.Modbus;
using Junevy.Communication.Tcp;

using ModbusClient client = ModbusClient.Create(
    new TcpClientChannelConfig { Host = "192.168.1.20", Port = 502 },
    new ModbusClientOptions { Framing = ModbusFraming.Rtu, UnitId = 3 });
```

### 一个连接，多个站

站号写在地址前缀里。一个客户端可以轮询整条 RS-485 总线。

```csharp
using Junevy.Communication.Core.Results;
using Junevy.Communication.Modbus;
using Junevy.Communication.Tcp;
using ModbusClient client = ModbusClient.Create(
    new TcpClientChannelConfig { Host = "192.168.1.10", Port = 502 },
    new ModbusClientOptions());
await client.ConnectAsync();
CommResult<ushort[]> first = await client.ReadUInt16Async("s=1;HR0", 1);
CommResult<ushort[]> second = await client.ReadUInt16Async("s=2;HR0", 1);
```

## 路径二：依赖注入（多连接、服务端推荐）

```csharp
using Junevy.Communication.Modbus;
using Junevy.Communication.Modbus.DependencyInjection;
using Junevy.Communication.Plc;
using Microsoft.Extensions.DependencyInjection;

ServiceCollection services = new ServiceCollection();
services.AddModbus();
ServiceProvider provider = services.BuildServiceProvider();

PlcClientFactory factory = provider.GetRequiredService<PlcClientFactory>();
IPlcClient client = factory.GetOrAdd("line-1", new ModbusClientConfig
{
    Transport = ModbusTransport.Tcp,
    Tcp = new TcpClientChannelConfig { Host = "192.168.1.10", Port = 502 },
    Options = new ModbusClientOptions { UnitId = 1 },
});
```

`ModbusClientConfig` 可以从配置绑定。`Transport` 选择 `Tcp`、`Udp` 或 `Serial` 之一，对应的配置必须存在。`AddModbus()` 与 `AddMelsec()` 可以在同一个工厂里共用。

## 地址与功能码速查

| 写法 | 含义 |
|---|---|
| `HR100` | 保持寄存器 100（线上地址 100，零基） |
| `IR3`、`C5`、`DI7` | 输入寄存器 3、线圈 5、离散输入 7 |
| `40101`、`400101` | Modicon 一基写法，等于 `HR100` |
| `HR100.5` | 寄存器 100 的第 5 位 |
| `s=2;HR100` | 站 2 的保持寄存器 100 |

| 操作 | 功能码 |
|---|---|
| 读位、读字 | 01、02；03、04 |
| 写单点、写单字（`UseSingleWriteFunctions`，默认开） | 05、06 |
| 写多点、写多字 | 0F、10（超出上限自动拆包） |
| 掩码写寄存器的位（`UseMaskWriteForBits`）、`MaskWriteRegisterAsync` | 16 |
| 读写多个寄存器（`ReadWriteMultipleRegistersAsync`） | 17 |

完整的上限、选项与错误映射见 [[协议细节/Modbus 协议]]。

## 新会话三个必记约定

1. **先看 `IsSuccess`，决策用 `ErrorKind`**。`RemoteError`（设备的异常响应）是终态，库不会重试，调用方也不要自己重试。
2. **地址是协议级零基地址**。`HR100` 就是线上地址 100；PLC 编程软件里的 "40101" 写法要用一基写法，不要按字面换算。
3. **每个客户端一次只有一个在途操作**。需要吞吐时使用多个客户端（工厂的多个 key），不要并发调用同一个客户端。

## 错误处理与重连

- 默认 `RetryCount = 0`、`Reconnect` 关闭。长运行服务按需开启：`RetryCount` 与 `RetryInterval`（如 3 与 200 毫秒）配合通道配置的 `Reconnect`。
- `DisconnectAsync` 之后不会自动连回，需要再次 `ConnectAsync()`。
- 错误分类的完整语义见 [[行为契约/错误处理与错误分类]]。
