## TestSupport 公共测试替身（2026-10-07 P1 新增）

| 文件 | 用途 | 关键成员 |
|---|---|---|
| `TestSupport/SilentTcpServer.cs` | 接受 TCP 连接、计数收到字节、**从不回复**（模拟不应答/半包从站） | `Start()`、`Port`、`AcceptedConnectionCount`、`ReceivedBytes`、`OnConnected` 回调、`Dispose()` |
| `TestSupport/FakeTransport.cs` | 继承 `ModbusTransportBase` 的无 I/O 假传输，用于确定性地测骨架的重试/重连/超时逻辑 | `Connected`、`OpenConnection(Async)Calls`、`SendFrameCalls`、`ReceiveFrameCalls`、`InvalidateConnectionCalls`、`OnOpenConnection(Async)`、`OnSendFrame`、`ReceiveResults` 队列 |

写新的骨架级测试用 `FakeTransport`（可断言"只发了一次""没有等待 RetryInterval"），写新的 TCP 集成测试用 `SilentTcpServer`（比 `TcpListener` 手工样板更省事，且能断言服务端收到的字节数）。

## ModbusProtocolTests（31 个）覆盖矩阵

| 主题 | 测试 |
|---|---|
| 帧构建 | MaskWrite RTU 帧、0x17 预编码 Data、TCP 帧字节级断言、协议来自参数而非请求、MaxRtuAduLength=256、0x07/0x08 帧、CheckRequest Diagnostics 1 字节数据 |
| TCP 解析 | TID 精确匹配（TID=7 收 8 必须失败）、从站不匹配、多写短帧不抛、异常响应含 Code |
| RTU 解析 | 多写短帧/坏 CRC/好 CRC、异常响应含 Code、ReportServerId 变长帧 |
| TCP 回环集成（TcpListener 假从站） | 懒自动重连（失败重试→新连接）、TID 顺序自增 0,1、异常响应终态不重试（请求计数==1）、非法 PDU 长度返回失败不抛、8 并发 Connect/Request 无交错异常、读超时归类 Timeout、RetryCount 重试后成功（请求 2–3 次）、取消 500ms 快速返回 Cancelled |
| 结果模型 | `Fail` 默认 Unspecified、可携带 Kind、`Describe()` 已知/未知码 |
| 配置 | Port 直接可写、VerifyPort 1–65535 全接受 |

**回环测试模式**（新测试的样板）：`TcpListener` + `Task.Run` 假从站，按"客户端重试会换新连接"逐个 accept（RetryCount=3 → 最多 4 连接）、回显请求 TID；listener.Stop() 后 pending Accept 可能永不完成（.NET 8 已知行为），断言不依赖服务器任务退出。新写 TCP 集成测试请沿用此模式，超时预算放宽（并发负载下 1s 会误报）。

## ModbusFactoryTests（23 个）覆盖矩阵

- DI：`AddModbusFactory` 单例、**工厂与管理器共享注册表**
- 生命周期：Dispose/DisposeAsync 清空、Dispose 后 `ObjectDisposedException`
- 校验：null config / 空 key / RTU 空 PortName 抛、默认值回填（0 → 2000 等）
- CRUD：重复 key TryAdd false、TryGet 有/无、TryRemove、GetRequired 类型不符抛、Keys 全量、空 key Get 返回 null、GetOrAdd 幂等
- 并发：GetOrAdd 16 并发竞态输家 Dispose（Moq 验证）、50 key 并行增删查 0 错误
- Builder：默认可用、两次 Build 独立、WithConnectionManager 共享、WithLoggerFactory 客户端用其 logger（SpyLoggerFactory）、null 参数抛
