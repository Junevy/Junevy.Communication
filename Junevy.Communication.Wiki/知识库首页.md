# Junevy.Communication 知识库

面向本仓库的知识库，包含两部分：

- **Modbus RTU/TCP 主站（客户端）通信类库**（`Junevy.Communication.Modbus`，net472 + net8.0 双目标）；
- **通讯通道族 P1**（`Junevy.Communication.Core / Channels / Tcp / Udp / Serial`，net472 + net8.0 双目标，版本 `1.0.0-preview.1`，未发布）；
- **地址型设备协议套件 P2**（`Junevy.Communication.Plc` 与 `Junevy.Communication.Melsec`，MELSEC MC 3E/4E over TCP/UDP、4C over 串口，版本 `1.0.0-preview.1`，未发布，MELSEC 未经真机验证）；
- **WebApi 客户端 P3.1**（`Junevy.Communication.WebApi`，REST 与 SOAP 1.1/1.2 主动上报 MES，net472 + net8.0 双目标，只依赖 Core，版本 `1.0.0-preview.1`，未发布；接收 MES 下发的 HTTP 服务端是 P3.2，**待办未排期**，见 [[WebApi/P3.2 HTTP 服务端（待办）]]）；
- **PLC 协议 P4**（`Junevy.Communication.Siemens` = S7comm over ISO-on-TCP，只针对 S7-1200/1500；`Junevy.Communication.Omron` = FINS over TCP；两者 net472 + net8.0 双目标、版本 `1.0.0-preview.1`、未发布、**均未经真机验证**；套件 `Junevy.Communication.Plc` 同期加入字节寻址、`ParseAddress`、字节访问、可选钩子与字符串扩展）。
- **共用件 P4.5**（无新协议，只有跨协议复用的部件）：Core 的 `BigEndianFields` 与 `SequenceCounter`、Plc 的 `PlcComponentWiring`；`CommResult` 的可空性标注。三个协议（MELSEC、S7、FINS）都改用它们，行为不变——见 [[架构设计/Plc 地址型设备协议套件]] 的"P4.5 变更"一节。
- **测试基建 P4.6**（**只改测试，生产代码零改动**）：共享测试库补 `Polling.WaitUntilAsync`、`Arrival.WithinAsync`、`LoopbackTcp`、`PlcByteMemory`；MELSEC 测试的 `McTestSupport.Hex` 与 `FakeByteChannel` 删除、改用 `HexVector.ToBytes` 与 `ScriptedByteChannel`。断言与测试数不变（各项目计数与 P4.5 一致，Channels +25）。见 [[测试/P4.6 测试基建整理（已完成）]] 与 [[测试/测试工程与验收方式]] 的"共享测试库"一节。
- **SECS 设备端 P5.1**（`Junevy.Communication.Secs`：SECS-II 消息模型 + HSMS-SS 会话 + **设备端**派发，net472 + net8.0，`1.0.0-preview.1`，未发布，**未经真机 / 真主机验证**）：直接引用 Core + Channels + Tcp，**不走 Plc 套件**、不实现 `IPlcClient`；Passive 监听 / Active 去连两种模式共用同一套派发与发送；含工厂与 `AddSecs()`。SECS-I、GEM、主机端角色**不在本期**（GEM 见 [[协议细节/P5.2 GEM（待办）]]）。见 [[协议细节/SECS-II 与 HSMS]]。
- **SDK 协议适配包 P6.2**（`Junevy.Communication.OpcUa` = OPC UA 客户端，**仅 net8.0**，SDK 为 OPC Foundation .NET Standard Stack 2.0.1（MIT），版本 `1.0.0-preview.1`）：只支持 `None` 安全策略与匿名登录；连接、读、写、浏览、订阅、逐项状态码、会话重连；NodeId 用标准文本（推荐 `nsu=` 命名空间 URI 形式）；`None` 策略下不需要客户端证书。**未经真实服务器验证**（只与进程内托管的官方服务器联调过）。见 [[协议细节/OPC UA 客户端]]。
- **SDK 协议适配包 P6.3**（`Junevy.Communication.Ftp` = FTP / FTPS 客户端，**仅 net8.0**，FluentFTP 55.0.0）：只做客户端，只用被动模式与二进制传输，不做 SFTP；按需连接、同一客户端上的操作串行、下载原子、上传非原子；操作中断线归 `Timeout`。**未经真实服务器验证**（只与进程内的模拟服务器联调过）。见 [[协议细节/FTP 客户端]]。
- **SDK 协议适配包 P6.1**（`Junevy.Communication.Mqtt` = MQTT 客户端，**仅 net8.0**，SDK 为 MQTTnet 5.2.0.1603（MIT），版本 `1.0.0-preview.1`）：公开 API 不出现 SDK 类型，SDK 只在 `Sdk/` 命名空间且全部 `internal`；含 MQTT 3.1.1 / 5.0、TLS、MQTT 5 属性、遗嘱、会话恢复式重连；**未经真实 Broker 验证**（只与进程内 MQTTnet.Server 联调过）。见 [[协议细节/MQTT 客户端]] 与 [[Agent协作/新增协议指南]] 第七节。
