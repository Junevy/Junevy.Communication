# Junevy.Communication 知识库

面向本仓库（Modbus RTU/TCP **主站（客户端）** 通信类库，net472 + net8.0 双目标）的知识库，共 20 篇正文笔记（不含本首页）。

> [!warning] 版本与时效
> 本知识库对应当前版本 **1.0.1**（`Junevy.Communication.Modbus.csproj` 的 `<Version>`），基线 commit 为 `74a3ed4`（master，"Feat: Bridge the Microsoft DI and Prism DryIoc"，工作树干净）。**2026-10-06 建库并按代码逐篇核对**，单元测试基线：**54/54 通过**。
> 与代码冲突时以代码为准。权威顺序：**代码 > 仓库 `AGENTS.md` > `CHANGELOG.md` > `docs/superpowers/plans/` 实施计划 > 本知识库正文**。
> 笔记内所有源码引用均为**文件级** `file://` 链接（相对仓库根，未写行号锚点），文件改名不会导致链接指向错误内容。

> [!tip] 给智能体的使用建议
> 1. **改动前先读** [[Agent协作/开发约定与验收基线]]（AGENTS.md 硬性约定：CHANGELOG、Skills、README 同步义务）与 [[Agent协作/常见陷阱与易错点]]（旧 API 名陷阱、错误契约边界）。
> 2. **写调用代码前查** [[API参考/功能码扩展方法]]（方法签名与数量限制）与 [[行为契约/错误处理与错误分类]]（`ModbusResult` / `ModbusErrorKind` 语义），不要凭 NModbus 或旧版记忆猜 API。
> 3. **理解行为先看** [[行为契约/重连重试与并发模型]]（RetryCount 语义、懒重连、请求锁）——重试/重连的行为细节都在这里，`README.md` 只是摘要。
> 4. **改完必须验收**：`dotnet test Junevy.Communication.Modbus.Tests` 需 **54/54 通过**；验收基线见 [[测试/测试工程与验收方式]]。
> 5. **改完同一会话内回写本库**：公共 API、行为契约、协议细节或设计决策变化时更新对应笔记与本页版本号/基线 commit；**不自行提交**，用 `git -C <本库路径> status --short` 汇报改动，由用户决定提交。
> 6. 本库笔记直接位于 `zh/content/<主题>/` 下，**未设每主题 Hub 页**（与 Junevy.EasyCamera 知识库的差异）：主题规模小，本首页即全量索引。
